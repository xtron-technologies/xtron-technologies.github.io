# XTron Technologies — Industrial Brutalism Landing Page

This is the calmer direction suggested after the neobrutalist version.

It is intentionally:

- more automotive/editorial
- more technical
- less playful
- less dependent on borders and box shadows
- built around the product imagery
- still influenced by neobrutalism through strong grids, hard typography and direct structure

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- No build step
- No framework

## Palette

Only four core colors are used:

- Near-black: `#0d0f12`
- Off-white: `#f2f0e8`
- XTron cyan: `#6ceef5`
- Electric blue: `#4f63ff`

## Usage

Place your images inside the `images/` folder using the expected names and open `index.html`.

The site can be deployed directly to GitHub Pages, Netlify, Vercel static hosting, or any standard web server.
